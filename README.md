# Idle Angler (beta)

Jogo idle de pesca. Este repositorio guarda **somente as versoes** do beta (sem codigo-fonte).

## Como jogar
1. Baixe o launcher: [Jogar-IdleAngler.bat](https://github.com/GustavoVecchiatti/idle-angler-releases/releases/latest/download/Jogar-IdleAngler.bat)
2. De dois cliques. Na primeira vez ele baixa o jogo (cerca de 110 MB); depois so baixa as atualizacoes (poucos MB) e abre.
3. O Windows pode mostrar o aviso SmartScreen: **Mais informacoes -> Executar assim mesmo** (o programa nao e assinado).

O jogo fica em `%LOCALAPPDATA%\IdleAngler`. Os saves ficam em `%APPDATA%\Godotpp_userdata\Idle Angler` e nao sao apagados nas atualizacoes.
